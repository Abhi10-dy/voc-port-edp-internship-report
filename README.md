# VOC Port EDP Internship Report

## Overview

This repository contains my internship report completed at V.O. Chidambaranar Port Authority (VOC Port), Thoothukudi.

The internship focused on Electronic Data Processing (EDP), port IT infrastructure, SAP ERP systems, data center operations, and the development of a Pension Portal for employee and pensioner document management.
